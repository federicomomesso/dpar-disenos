# Dpar Diseños · Muebles a medida en Ramos Mejía

Web de una carpintería con fábrica propia: cocinas, placares, vestidores, racks de TV y mostradores para comercios.

**Sitio:** https://dpar.pages.dev

![Portada de Dpar Diseños](share.jpg)

## Qué tiene

- Catálogo de muebles y galería de trabajos reales.
- Pedido de presupuesto directo por WhatsApp.
- Diseño adaptado a celular, carga rápida y SEO local (Ramos Mejía, Buenos Aires).

## Tecnología

HTML, CSS y JavaScript sin frameworks. Publicada en Cloudflare Pages.

## Publicar

```powershell
.\publicar.ps1
```

Requiere `npx wrangler login` una vez.
